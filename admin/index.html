카드뉴스 관리

API 키를 넣고 생성을 누르면 AI 요약과 인스타그램 카드뉴스를 만들어 저장소에 올립니다. 게시 전에 꼭 내용을 검토하세요.

API 키

키는 이 탭에만 보관되고 탭을 닫으면 지워집니다. Claude 키는 Anthropic API로, GitHub 토큰은 GitHub API로만 전송됩니다. 호출 요금은 입력한 키의 계정에 청구됩니다. 토큰은 이 저장소만 선택한 fine-grained 토큰(Contents: Read and write)을 쓰세요. 토큰이 없으면 미리보기·ZIP만 됩니다.

불러오는 중…
  • 생성·재생성은 이 브라우저에서 바로 실행됩니다. 1~2분 걸리니 끝날 때까지 탭을 닫지 마세요.
  • 커밋 후 블로그(GitHub Pages)에 반영되기까지 1~2분 더 걸립니다. 그 전에도 이 탭에서는 새 결과를 미리볼 수 있습니다.
