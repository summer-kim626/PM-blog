## 2. 개요

블로그 글을 쓰고 나면 SNS 홍보용 요약과 카드뉴스를 **따로 다시 만들어야 해서** 홍보를 자주 건너뛰게 된다.
이 프로젝트는 `posts/`에 새 글을 올리면 **GitHub Actions가 AI로 글을 요약하고, 인스타그램 카드뉴스(1080×1350, 5~7장) 초안을 자동으로 만들어** 블로그와 저장소에 올려준다.
관리자는 생성된 카드를 검토하고 내려받아 올리기만 하면 되므로, **"글쓰기 → 홍보" 사이의 손작업을 없애는 것**이 목표다.

## 3. 문제 정의

> **1인 블로그 운영자는 글을 쓴 뒤 홍보용 카드뉴스를 따로 만들 시간이 없어, 글을 올려도 SNS 홍보를 건너뛰고 유입 기회를 놓친다.**

### 3.1 현재 상황 (ASIS)

- 글 1편을 쓰고 나면 **요약 → Canva로 카드 제작 → 캡션 작성**을 다시 해야 해서 **추가로 1시간 이상**이 든다.
- 그 시간이 부담스러워 홍보를 자주 건너뛰고, 그 결과 블로그 유입이 늘지 않는다.
- 범용 AI 챗봇이나 Canva 템플릿 같은 대체 방법도 매번 복사·붙여넣기와 편집이 필요하고 블로그와 연결되지 않는다.

### 3.2 문제 목록

| 문제                                                          | 타깃        | 우선순위 |
| ------------------------------------------------------------- | ----------- | -------- |
| 글을 카드뉴스로 옮길 때 요약·디자인·카피 작성이 매번 반복된다 | 관리자(나)  | 핵심     |
| 홍보가 귀찮아 SNS 공유를 건너뛰고, 그래서 유입이 늘지 않는다  | 관리자(나)  | 핵심     |
| 글이 길면 독자가 핵심을 빨리 파악하기 어렵다                  | 블로그 독자 | 보조     |

### 3.3 타깃 고객

- **1순위 — 관리자(나):** 주 1~2회 PM 학습 글을 쓰는 취업 준비생. 글을 쓴 뒤 홍보 작업에 쓸 시간이 부족하다.
- **2순위 — 독자:** 출퇴근길에 모바일로 PM 콘텐츠를 훑어보는 주니어 기획자.

### 3.4 환경 분석 요약

| 구분 | 내용                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------- |
| 강점 | 정적 HTML 블로그와 GitHub Actions 자동화(날씨 봇) 운영 경험이 있고, 글이 HTML이라 AI 입력으로 쓰기 쉽다 |
| 약점 | 1인 운영이라 시간이 적고, SNS 운영 경험과 유입 채널이 부족하다                                          |
| 기회 | 인스타그램에서 카드뉴스형 정보 콘텐츠가 많이 소비되고, LLM 요약 비용이 낮아졌다                         |
| 위협 | AI 문구의 사실 오류가 신뢰를 해칠 수 있고, 플랫폼 정책에 따라 자동 업로드가 막힐 수 있다                |

## 4. 해결 방향 (요약)

### 4.1 범위

| 범위   | 항목                                                                    |
| ------ | ----------------------------------------------------------------------- |
| Must   | 글 발행 시 자동 요약 + 카드뉴스 초안 이미지 생성                        |
| Should | 글 상단 AI 3줄 요약 노출, 캡션·해시태그 생성                            |
| Could  | 카드 디자인 테마 선택                                                   |
| Won't  | 인스타그램 자동 업로드 (비즈니스 계정·API 심사가 필요해 이틀 안에 불가) |

### 4.2 기능 요구사항

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 새 글 감지 | `posts/*.html` 추가·수정 푸시 시 GitHub Actions 실행 |
| F2 | 본문 추출 | HTML에서 제목·본문 텍스트만 추출 |
| F3 | AI 생성 | 3줄 요약, 카드별 문구(표지·핵심 3~5장·CTA), 캡션·해시태그를 JSON으로 생성 |
| F4 | 카드 이미지 렌더링 | HTML 카드 템플릿에 문구를 넣고 1080×1350 PNG로 캡처 |
| F5 | 결과 저장 | `data/cardnews/<slug>/`에 JSON·PNG 커밋 |
| F6 | 블로그 노출 | 글 상단 3줄 요약, 카드뉴스 미리보기·다운로드 페이지 |

## 5. 성공 기준 (OKR)

- **O:** 글을 올리면 바로 홍보까지 이어지는 블로그 운영 흐름을 만든다
- **KR1:** 글 1편당 홍보 콘텐츠 제작 시간을 60분에서 10분 이하로 줄인다
- **KR2:** 발행 글 중 카드뉴스가 생성되는 비율 100%
- **KR3:** 생성된 카드를 수정 없이 또는 1회 이하 수정으로 쓰는 비율 70% 이상

## 6. 주요 리스크

- **AI 요약의 사실 오류:** "AI 초안"으로 표기하고, 프롬프트에 "본문에 없는 내용 금지" 규칙을 둔다
- **API 키 노출:** 키는 GitHub Secrets에만 보관하고 브라우저 코드에 넣지 않는다
